어떻게 동작하나 — 대표 시나리오

사용자가 저녁 7시 반에 "KT 메뉴 뭐야?"라고 물었다고 하면:

  1. menu_tool.get_menu() 호출 → 내부적으로 menu_agent.parse_query()가 업체="KT", 날짜/요일/끼니는 미지정으로 추출.
  2. 끼니 미지정 + 19시 이후이므로 _resolve_meal_type이 "다음 식단 제공일 점심"으로 판단, 날짜는 내일로 계산.
  3. 업체가 "KT"로 명시되어 있으므로 조건 검색 모드로 SQLite menu_repository.get_by_condition(organization="KT", menu_date=내일, meal_type="점심") 조회.
  4. 결과가 있으면 "내일 KT 점심 메뉴는 ...입니다." 형태 답변 생성, 원본 이미지 경로도 함께 반환.
  5. 결과가 없으면 다른 날짜로 대체하지 않고 "해당 날짜에는 등록된 식단이 없습니다."를 그대로 반환.

반대로 "이번 주에 돈가스 나오는 날이 언제야?"처럼 날짜 자체를 찾는 질문은 "언제/나오는" 키워드를 감지해 의미 검색(해싱 기반 TF 벡터 + 코사인 유사도)으로 전환됩니다.
